# Dockerized Diagnostic CLI

DevOps Practical Assignment 2.

A portable Bash command-line utility supporting:

- `diagnostic system`
- `diagnostic network <host>`
- `diagnostic disk`
- `diagnostic help`

The application runs locally or inside a Docker container.

Exit codes:
- 0: Success
- 1: Operational failure
- 2: Invalid command or input

Docker setup, Compose usage, testing instructions and
assumptions are documented in the completed release.
